通常のZstandard圧縮 → Base8192 に変換。圧縮・復号はブラウザー内で行います。文章はサーバーに送信しません。

Zstd WASM は初回のみ jsDelivr CDN から読み込みます。ネット接続が必要です。辞書ファイルは不要です。

ここにBase8192の出力が表示されます。
準備完了
—元データ UTF-8 bytes
—圧縮前 bytes
—Zstd bytes
—Base8192 symbols

Xの文字数ウェイトを概算します。実際のXカウントとは完全一致しない場合があります。

方式と注意点

辞書を使わない通常のZstandard圧縮です。圧縮データはBase8192に変換して文字列として出力します。復号にも辞書は必要ありません。

Base8192の文字セットはUnicodeの文字カテゴリから決定的に生成します。Unicodeデータベースのバージョンが異なる環境では文字セットが一致しない可能性があります。異なる端末間での復号には、同一の文字セットを固定・配布する仕組みが必要です。

Unicode文字のX上のウェイトは文字種によって異なります。ここでのカウントは目安です。140ウェイトを超えた場合は、分割投稿するか、別の共有方法を検討してください。
